# 🛒 מזווה חכם (Smart Pantry)

אפליקציית **PWA** (Progressive Web App) לניהול מלאי וקניות לבית — רשימת קניות
**מודעת-מלאי** שנבנית לבד לפי מה שחסר, עם חיזוי צריכה, התראות תפוגה ומיון לפי מסלול
הסופר. עיצוב נייטיב mobile-first, מסך אחד עם טאבים תחתונים. Vanilla HTML/JS, עברית RTL.

## הפעלה

ה-PWA דורש הגשה דרך שרת (Service Worker ו-ES modules לא עובדים מ-`file://`):

```
cd smart-pantry
npx serve .
# ואז להיכנס ל-http://localhost:3000
```

בטלפון: נכנסים לכתובת, ואז **שיתוף → הוסף למסך הבית** — וזה נפתח כמו אפליקציה
אמיתית (מסך מלא, אייקון, עובד אופליין). בהפעלה ראשונה נטענים מוצרי דוגמה.

## אפליקציה אחת, שלוש תצוגות (טאבים תחתונים)

- **🛒 רשימה** — רשימת הקניות שנבנית לבד, מקובצת לפי מסלול הסופר. ✓ מסמן שנקנה.
- **🥫 מזווה** — כל המלאי: כמויות (stepper), חיפוש, סינון לפי קטגוריה / "רק מה שחסר".
- **＋ (FAB)** — הוספת מוצר מהירה (bottom sheet).
- **☰ עוד** — סטטיסטיקה, סטטוס סנכרון, התקנה, איפוס.

## הפיצ'רים החכמים (Phase 1 — קיים)

- **סף מינימום** → מתחת לסף המוצר קופץ אוטומטית לרשימה (נגמר / עומד להיגמר).
- **חיזוי צריכה** — מהיסטוריית הרכישות ("צפוי להיגמר בעוד ~N ימים").
- **תפוגות** — התראת "לאכול קודם" למניעת בזבוז.
- **מיון לפי מסלול הסופר**, קבוע מול חד-פעמי, טיפים התנהגותיים מבוססי-מחקר.

## סנכרון בית (Firebase — אופציונלי)

האפליקציה עובדת מקומית (`localStorage`) בלי שום הקמה. לסנכרון חי בין כל מכשירי הבית:
מלאו את `firebase-config.js` (במקום `REPLACE_ME`) — `firebase-sync.js` יזהה אוטומטית.

## מפת דרכים

- **Phase 1b — מחירים:** GitHub Action שמושך XML של הרשתות (חוק שקיפות מחירים), מתאים
  לפי ברקוד, כותב מחירים + מבצעים ל-Firestore. (שלד `scripts/`, `.github/workflows/`.)
- **אולי מתישהו — וואטסאפ:** WhatsApp Cloud API → Cloudflare Worker → Firestore.
  מוקפא בכוונה: לכידה מהירה כבר מכוסה ע"י ה-PWA, והזנת טקסט חופשי יורשת את בעיית
  מיפוי שם→מוצר בלי סורק/הצעות. לשקול רק אם בני-בית לא-מתקינים ירצו להוסיף בהודעה.

## מבנה

| קובץ | תפקיד |
|------|------|
| `index.html` | מעטפת ה-SPA: header, תצוגות, טאבים תחתונים + FAB |
| `app.js` | המוח: מודל נתונים, חיזוי, סטטוס, רשימה, טיפים, persistence, אמוג'י |
| `ui.js` | בקר ה-UI: רינדור התצוגות, טאבים, sheets, אינטראקציות |
| `styles.css` | עיצוב נייטיב בהיר (RTL, mobile-first) |
| `manifest.webmanifest` / `sw.js` / `icon.svg` | שכבת ה-PWA (התקנה + אופליין) |
| `firebase-config.js` / `firebase-sync.js` | סנכרון בית אופציונלי |
