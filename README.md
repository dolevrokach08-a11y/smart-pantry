# 🛒 מזווה חכם (Smart Pantry)

ניהול מלאי וקניות לבית — רשימת קניות **מודעת-מלאי** שנבנית לבד לפי מה שחסר, עם
חיזוי צריכה, התראות תפוגה, ומיון לפי מסלול הסופר. בנוי Vanilla HTML/JS, עברית RTL.

## הפעלה מהירה

האפליקציה עובדת מיד, בלי שום הקמה — היא local-first (הנתונים נשמרים ב-`localStorage` בדפדפן):

```
# מספיק לפתוח את index.html בדפדפן, או להריץ שרת סטטי קטן:
npx serve .
# ואז להיכנס ל-http://localhost:3000
```

- **`index.html`** — רשימת הקניות + דשבורד
- **`pantry.html`** — ניהול המזווה (הוספה, כמויות, ספים, תפוגות, ברקוד)

בהפעלה ראשונה נטענים כמה מוצרי דוגמה כדי שיהיה מה לראות.

## הפיצ'רים החכמים (Phase 1 — קיים)

- **סף מינימום** לכל מוצר → כשהכמות יורדת מתחת לסף, הוא קופץ אוטומטית לרשימה (נגמר / עומד להיגמר).
- **חיזוי צריכה** — מתוך היסטוריית הרכישות מחושב קצב ("צפוי להיגמר בעוד ~N ימים") ומזכיר עוד לפני שנגמר.
- **תפוגות** — התראת "לאכול קודם" למוצרים שמתקרבים לתפוגה (מניעת בזבוז).
- **מיון לפי מסלול הסופר** — הרשימה מקובצת לפי קטגוריות בסדר ההליכה בסופר.
- **קבוע מול חד-פעמי** — מוצרי בסיס שתמיד צריך מול קניות חד-פעמיות.
- **טיפים התנהגותיים** — נאדג'ים מבוססי-מחקר (אל תקנו רעב, קנייה מרוכזת, וכו').

## סנכרון בית (Firebase — אופציונלי)

כדי שכל בני הבית יראו ויעדכנו את אותה רשימה בזמן אמת:

1. צרו פרויקט Firebase + Firestore (תוכנית Spark החינמית מספיקה).
2. מלאו את הקרדנציאלס ב-`firebase-config.js` (במקום ערכי `REPLACE_ME`).
3. רעננו — `firebase-sync.js` יזהה את הקונפיג ויפעיל סנכרון אוטומטית.

עד שזה ממולא, האפליקציה רצה מקומית לגמרי.

## מפת דרכים

- **Phase 1b — מעקב מחירים ישראלי:** GitHub Action מתוזמן שמושך XML של הרשתות
  (חוק שקיפות מחירים), מתאים לפי ברקוד, וכותב מחירים + מבצעים ל-Firestore.
  (שלד תחת `scripts/` ו-`.github/workflows/`.)
- **Phase 2 — וואטסאפ:** WhatsApp Cloud API → Cloudflare Worker webhook → Firestore,
  לעדכון מהיר ("נגמר חלב") והתראות פרואקטיביות.

## מבנה

| קובץ | תפקיד |
